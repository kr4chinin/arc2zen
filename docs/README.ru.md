# Перенос Arc → Zen на macOS

Инструмент готовит перенос в отдельной копии, показывает количество записей и
применяет результат только отдельной командой. Перед применением он сохраняет
полный профиль Zen для отката.

Переносятся пространства, значки, цвета, закреплённые вкладки, Essentials,
открытые веб-вкладки, история, закладки с папками, адреса, значения обычных полей
и поисковые сокращения. Cookies и набор горячих клавиш включаются отдельно.

Это ранняя версия. Исходные адаптеры проверялись на одном Mac с Arc 1.170.0 и Zen
1.23.4b. Новый CLI проверяется на искусственных профилях. Поддерживается профиль
Arc **Default** и пространства Zen без контейнеров. Папки среди закреплённых
вкладок пока не поддерживаются; обычные папки закладок поддерживаются.

## Установка

Нужны Python 3.11+, библиотека LZ4, установленные Arc и Zen. Оба браузера нужно
хотя бы раз открыть и закрыть обычным способом.

```sh
brew install python lz4
git clone https://github.com/kr4chinin/arc2zen.git
cd arc2zen
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
arc2zen discover
```

Пока репозиторий private, для клонирования нужен доступ и авторизация в GitHub.

## Подготовка

Выбери нужный профиль Zen из вывода `discover`. Если профилей несколько,
инструмент сам выбирать не будет. Полностью закрой **Arc и Zen через Cmd+Q**.
Не открывай их до завершения `apply`.
Вывод `discover` отмечает основной профиль; отсутствующий основной профиль не
приводит к автоматическому выбору запасного.

```sh
arc2zen prepare --zen-profile "/точный/путь/из/discover"
```

По умолчанию готовится всё перечисленное выше, кроме cookies и горячих клавиш.
Для полного набора:

```sh
arc2zen prepare --zen-profile "/точный/путь/из/discover" \
  --parts spaces,tabs,history,bookmarks,addresses,forms,search,cookies,keyboard
```

Можно выбрать отдельные части: например, `--parts history,bookmarks`. Для вкладок
нужны уже перенесённые пространства либо `spaces` в том же запуске.
Часть `spaces` включает закреплённые вкладки и Essentials, а `tabs` переносит
только открытые веб-вкладки. Неотображённые токены адресов видны в отчёте как
число и идентификаторы типов, без личных значений.
Вкладки с неподдерживаемыми URL, включая локальные файлы, пропускаются со
счётчиком, а не останавливают весь перенос.

`prepare` не меняет рабочий профиль. Данные подготовки находятся вне репозитория,
обычно в `~/Library/Application Support/arc2zen/runs/`. Требуется место для снимка
исходных данных, изменяемых файлов и полной резервной копии Zen при применении.
Путь каталога печатается до подготовки и остаётся доступным при ошибке.
Незавершённый каталог можно удалить самостоятельно, если он больше не нужен.

Если выбраны cookies, macOS может запросить доступ к **Arc Safe Storage**.
Подтверди текущее системное окно самостоятельно. При отказе или тайм-ауте
подготовка остановится. Для повторной попытки используй новый каталог запуска.
Ключ хранится только в памяти процесса. Значения cookies попадут в локальную
копию и затем в стандартные хранилища Zen, как и при обычной работе браузера.

## Применение

Проверь числа в отчёте и выполни **точную команду `arc2zen apply --run ...`**,
которую напечатал `prepare`. Она проверит, что профиль и подготовленные файлы не
изменились, создаст полную резервную копию и заменит только выбранные файлы.
Если Zen успел открыться, подготовь новый запуск.
Если прервётся копирование бэкапа до установки файлов, ту же команду `apply`
можно повторить без новой подготовки и повторного доступа к Keychain.

Открой Zen и проверь пространства, **Другие закладки → Arc Bookmarks**, историю,
автозаполнение и вход на важные сайты. Некоторые сайты попросят войти заново.

Набор `keyboard` задаёт Cmd+D для закрепления вкладки, Cmd+S для боковой панели,
Cmd+Option+Return для дублирования и отключает конфликтующие сочетания. Это
готовый набор, а не перенос произвольных сочетаний из Arc.

Пароли импортируются встроенным средством Zen из CSV. Расширения устанавливаются
из официального каталога Firefox. Подробнее: [пароли и расширения](PASSWORDS-AND-EXTENSIONS.md).

## Откат

Закрой оба браузера и выполни:

```sh
arc2zen restore --run "/полный/путь/каталога/запуска"
```

Если выбранные файлы изменились после переноса, команда остановится. Флаг
`--discard-new-data` разрешает откат с потерей более новых изменений в этих файлах.
Сначала инструмент создаст ещё одну полную копию текущего профиля. Невыбранные
файлы, включая пароли, остаются на месте. Детали аварийного восстановления:
[Compatibility → Recovery](COMPATIBILITY.md#recovery).

## Что можно публиковать

В этом репозитории только код, инструкции и выдуманные тестовые данные. Каталоги
запусков содержат личные данные, cookies и резервные копии. **Не загружай их в
GitHub и не прикладывай к issues.** Отчёт содержит числа, манифест — также локальные
пути и хеши. После проверки переноса сохрани резервные копии на нужный срок и
удали ненужные каталоги запусков самостоятельно.
